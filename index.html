PhD Council · Event automation

Email everyone a calendar invite when they register

A first-timer's guide. Follow the six steps in order — tick each one as you go. No coding, nothing to install.

⏱ About 30 minutes 🧰 Microsoft Forms + Power Automate 🔁 Reuse for any event

  1. First, create your registration form

    Everything starts from a Microsoft Form — that's how people sign up.

    • Go to forms.office.com and follow the sign-up or sign-in process with your UHasselt staff account.
    • Click New Form, give it a title, and add your questions (at least a name and a staff email question).

    The email question is the important one — the invite is sent to whatever address people enter there.

  2. Start a new flow

    The “flow” is the little robot that watches your form and sends the emails.

    • Go to flow.microsoft.com and follow the sign-up or sign-in process with your UHasselt staff account.
    • Click Create → Automated cloud flow. Give it a name like “Event invite”.
    • For the trigger, search Microsoft Forms and pick When a new response is submitted. Click Create.
    • In that first step, set Form Id to the title of the form you just made. It should show up in the dropdown options.

    When you set Microsoft Forms as the trigger, you might have to approve a connection between Microsoft Power Automate & Forms.

  3. Add the calendar file

    This holds the event details that go into people's calendars.

    • Click the + under your first step → Add an action.
    • Search Compose and add it. Rename it to “Calendar file”.
    • Paste the text below into its Inputs box, then change the six highlighted lines to match your event.
    Calendar file (paste this)
    BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//UHasselt PhD Council//Events//EN
METHOD:PUBLISH
BEGIN:VTIMEZONE
TZID:Europe/Brussels
BEGIN:DAYLIGHT
TZOFFSETFROM:+0100
TZOFFSETTO:+0200
TZNAME:CEST
DTSTART:19700329T020000
RRULE:FREQ=YEARLY;BYMONTH=3;BYDAY=-1SU
END:DAYLIGHT
BEGIN:STANDARD
TZOFFSETFROM:+0200
TZOFFSETTO:+0100
TZNAME:CET
DTSTART:19701025T030000
RRULE:FREQ=YEARLY;BYMONTH=10;BYDAY=-1SU
END:STANDARD
END:VTIMEZONE
BEGIN:VEVENT
UID:my-event-2026@uhasselt.be
DTSTAMP:20260101T000000Z
DTSTART;TZID=Europe/Brussels:20260925T150000
DTEND;TZID=Europe/Brussels:20260925T170000
SUMMARY:My event name
LOCATION:Where it is\, Campus
DESCRIPTION:One line about the event.
END:VEVENT
END:VCALENDAR
    Line
    What to put
    UID
    A unique tag for this event. Use a fresh one for every new event, e.g. wellbeing-2026@uhasselt.be.
    DTSTART
    Start date + local time. 20260925T150000 = 25 Sep 2026, 3:00 PM. Just type the normal Belgian time.
    DTEND
    End date + time, same format.
    SUMMARY
    The event's name that will be displayed in their calendar.
    LOCATION
    Where it is. Put a "\" before any comma.
    DESCRIPTION
    A small description of the event for their calendar.

    You don't need to touch the timezone block at the top — it quietly handles summer vs winter time so your times are always right.

  4. Read the person's details

    • Click + under the Calendar file step → Add an action.
    • Search Microsoft Forms → pick Get response details.
    • Set Form Id to your form.
    • Click the Response Id box, type in "/", and click on ⚡ Insert dynamic content.
    • Choose Response Id from the list that pops up.

  5. Send the email with the invite

    • Click + under the Get response details step → Add an action.
    • Search Office 365 Outlook → pick Send an email (V2).
    • To: Click on ⚙️ next to it and choose ⚡ Use dynamic content. Now, type in "/", and click on ⚡ Insert dynamic content. Choose your form's staff email address answer from the list.
    • Subject and Body: Write your confirmation message (date, time, place). To personalise it, start the body with Dear and then, using dynamic content, pick your form's name answer from the list — so each email opens “Dear [their name]”.
    • Click Show all to find more options:
      • From (Send as): type phdcouncil@uhasselt.be so the email comes from the council, not your personal account.
      • Attachments → Add new item:
        • Name: myeventname.ics
        • Content: Choose Outputs of your Calendar file step using dynamic content.

    If the To box can't find your email answer, you haven't enabled dynamic content for that box — enable it.

  6. Save and test it

    • Click Save (top right).
    • Open your form and submit one test answer as yourself.
    • Check your inbox — an email with myeventname.ics should arrive within a minute.
    • Tap the file. Your calendar should offer to add the event at the right time. 🎉

    Once one test works, you're done. It now runs by itself for everyone who registers.

To see who's coming

Open your form → Responses → Open in Excel. That list of everyone who registered is your attendance sheet — and the file you share with the Doctoral Schools afterward.

If something goes wrong
The email arrived, but with no recipient / a blank “To”
The To box isn't linked to your email question. Open the email step and set To to your form's staff email answer.
The calendar file won't open
In the email step's attachment Content, replace what's there with base64(outputs('Calendar_file')) and test again.
The event shows the wrong time
Make sure you pasted the whole block including the timezone section, and typed normal Belgian time in DTSTART/DTEND (don't convert anything).
People got two copies of the event
Keep the same UID if you resend the same event. Only change the UID for a genuinely new event.
