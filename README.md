# UHasselt PhD Council — Website Proposal

This repository contains a sample webpage developed by a member of the UHasselt PhD Council as a design proposal for the council's official web presence. It is intended to serve as a starting point for discussion and further development by the web team.

## Purpose

The page demonstrates how the PhD Council could present itself online, covering key sections such as:

- **About** — mission and role of the PhD Council
- **Upcoming Events** — announcements for community events such as After-Work Drinks
- **Initiatives** — ongoing activities organised by the council
- **Members** — an overview of the current executive committee
- **Contact** — ways to get in touch with the council

## Status

> ⚠️ This is a **proposal and work in progress**, not an official UHasselt webpage.  
> Content, names, links, and design are subject to change pending review and approval.

## How to View

Open `index.html` in any modern web browser. No build tools or dependencies are required — the page is self-contained HTML and CSS.

Alternatively, the page is hosted via GitHub Pages at:  
`https://<your-username>.github.io/<repo-name>/`
